## 🎯 Overview

**Temporary File Upload (Up to 1GB)** is a privacy-first file sharing service for sending large files quickly — no account, no sign-up, no permanent footprint. Every upload gets a short link, optional password protection, and an **automatic expiration** (from 1 hour to 7 days).

It's designed for the moments when email attachments fail and cloud drives feel heavy: sending a presentation to a colleague, sharing a build artifact with a tester, or pushing a 900 MB video to a client — quickly and safely.

### 🧩 What It Provides

| Feature | Description |
|---------|-------------|
| 📤 **Up to 1 GB** | Per file size |
| 🔗 **Instant link** | Share immediately |
| ⏱️ **Auto-expiry** | 1h to 7 days |
| 🔐 **Password** | Optional access code |
| 🔒 **Encryption** | At rest + in transit |
| 🗑️ **One-time download** | Self-destruct option |
| 📊 **Download counter** | Track usage |
| 🚫 **No account** | Zero-friction |

## 🔌 API Reference

### 📤 Upload Endpoint

```bash
curl -X POST https://api.tmp.example/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@myfile.zip" \
  -F "ttl=86400" \
  -F "password=secret123" \
  -F "one_time=false"
```

### 📥 Response

```json
{
  "id": "abc123",
  "url": "https://tmp.example.com/abc123",
  "expires_at": "2025-01-16T14:23:11Z",
  "size": 934582016,
  "sha256": "9a1c9c5c...",
  "one_time": false
}
```

### 📊 Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/upload` | POST | Upload a file |
| `/file/:id` | GET | Download |
| `/file/:id/meta` | GET | Metadata |
| `/file/:id` | DELETE | Delete |
| `/stats/:id` | GET | Download count |
| `/health` | GET | Status check |

## 💻 CLI Tool

### 🪜 Install

```bash
npm install -g tmp-upload
```

### 📄 Usage

```bash
# Simple upload
tmp-upload myfile.zip

# With password and expiry
tmp-upload myfile.zip --password secret --ttl 24h

# One-time download
tmp-upload report.pdf --one-time
```

### 🎛️ Options

| Flag | Purpose |
|------|---------|
| `--password` | Access code |
| `--ttl` | Expiry (1h, 24h, 7d) |
| `--one-time` | Self-destruct |
| `--name` | Custom filename |
| `--quiet` | No progress bar |
